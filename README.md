# dotfiles

My personal configs: Emacs, shell dotfiles, and app configs.

## Contents

- `emacs/` — Emacs config (`~/.config/emacs/`)
  - `init.el` — main config (COSMIC dark, IDE-like, F5/F6/F7/F8 build keys)
  - `cosmic-theme.el` — COSMIC theme
  - `matugen-theme.el` — wallpaper-derived theme (generated by matugen)
  - `elpa/` — bundled plugins (24 packages: orderless, vertico, marginalia,
    consult, corfu, cape, embark, embark-consult, which-key, projectile,
    magit + deps, doom-modeline, nerd-icons, rainbow-delimiters,
    exec-path-from-shell, etc.)
- `shell/` — shell dotfiles (`~/`)
  - `.bashrc`, `.bash_profile`, `.profile`, `.gitconfig`
- `nvim/` — Neovim config (`~/.config/nvim/`, LazyVim + matugen colors)
- `btop/` — btop config (`~/.config/btop/btop.conf`)
- `matugen/` — matugen wallpaper-colors setup (`~/.config/matugen/`)
  - `config.toml`, `templates/`, `scripts/`, `themes/`

## Install

```bash
git clone https://github.com/doctorit9/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

`install.sh` symlinks (with backup of existing files to `~/.dotfiles.bak/<timestamp>/`):
- `emacs/*` → `~/.config/emacs/` + `emacs/elpa/` → `~/.config/emacs/elpa/`
- `shell/.bashrc` → `~/.bashrc`, etc.
- `nvim/` → `~/.config/nvim/`
- `btop/btop.conf` → `~/.config/btop/btop.conf`
- `matugen/` → `~/.config/matugen/` (config, templates, scripts, themes only; `generated/` is rebuilt by matugen)

### Notes
- Emacs plugins are bundled in `emacs/elpa/`. If `elpa/` is missing,
  `init.el` auto-installs them on first run via MELPA. `eln-cache/`,
  `elpa/archives/`, `*.signed`, `gnupg/`, `history`, `recentf`, `places`
  are local state and are **not** tracked (see `.gitignore`).
- `shell/.bashrc` sources `~/.config/opencode/.figma-mcp.env` if present — that file itself is **never** committed (contains secrets). `install.sh` does not touch it.
- Update `shell/.gitconfig` user email/name after install if needed.
- Matugen `config.toml` contains absolute `/home/doctorit` paths — adjust them for other machines/users.
